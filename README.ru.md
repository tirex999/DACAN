# DACAN 0.43 для Linux x86-64 и RTX 2080 Ti

Срок жизни снимка диалога по умолчанию — 480 минут (8 часов). Укажите --conversation-cache-expire-min N в аргументах движка, чтобы выбрать другой срок. Значение 0 отключает истечение по времени. Снимки занимают оперативную память и могут быть вытеснены раньше. Если в профиле уже указан срок, он имеет приоритет.

Для запуска нужны SM75, CUDA Runtime и cuBLAS 13, glibc 2.35 или новее и рабочая установка сервера с моделью. В архив входят исполняемый файл dacan и лицензия. Команда ./dacan --version выводит dacan 0.43.

## Как поставить рядом со сборкой 6

Из каталога установки DACAN скачайте архив и файл контрольных сумм в отдельную папку. После успешной проверки архив распакуется.

```sh
mkdir -p engine-sm75-0.43
(
  cd engine-sm75-0.43 &&
  base=https://github.com/tirex999/DACAN/releases/download/v0.43 &&
  curl -fL -O "$base/dacan-linux-x64-sm75-0.43.zip" &&
  curl -fL -O "$base/SHA256SUMS.txt" &&
  sha256sum -c SHA256SUMS.txt &&
  unzip dacan-linux-x64-sm75-0.43.zip
)
```

Скопируйте рабочий JSON модели в том же каталоге под именем `dacan-sm75.json`. В копии укажите в поле верхнего уровня `exe` абсолютный путь к `engine-sm75-0.43/dacan`. Пути к модели, токенизатору и библиотекам CUDA уже заданы в конфигурации. Чтобы запустить сборку на тех же картах, остановите текущий сервер и выполните команду из каталога DACAN в его окружении Python.

```sh
DACAN_SM75_NVFP4_PREFILL=1 python -m serve.server --engine dacan --config dacan-sm75.json --host 127.0.0.1 --port 8080
```

По умолчанию ускорение чтения промпта для SM75 выключено. Для возврата остановите этот экземпляр и запустите DACAN с исходным конфигом модели.
