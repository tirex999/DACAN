# DACAN для RTX 2080 Ti под Linux

Отдельная сборка текстового движка для Linux x86-64 и NVIDIA Turing SM 7.5. Проверена на двух RTX 2080 Ti по 22 ГБ и двух Xeon Gold 8358 с моделью Qwen3.8-Flash-Next NVFP4 + Q8. Нужны glibc 2.35 или новее, CUDA Runtime 13 и cuBLAS 13. Для установки понадобится рабочая сборка DACAN 6 с CUDA 13 и подготовленной моделью. [Стабильный выпуск и установщик](https://github.com/tirex999/DACAN/releases/tag/v0.1.42-build6)

## Исправления кэша промптов

Если клиент отключается во время чтения промпта, движок сохраняет обработанный префикс для повторного запроса. Если в ОЗУ мало места для ещё одного снимка диалога, отказ в сохранении оставляет прежние снимки доступными.

| Повторный запрос на сервере с двумя слотами | Из кэша | Дочитано |
| --- | ---: | ---: |
| Промпт из 71 461 токена, соединение закрылось во время чтения | 71 454 | 7 |
| Промпт из 71 449 токенов, соединение закрылось после того, как слот уступил очередь | 16 384 | 55 065 |

Оба запроса вернули ожидаемый ответ. В отдельном тесте с нехваткой ОЗУ после отказа в сохранении уцелели все 12 прежних снимков. Из одного восстановились 296 622 токена. В тестах повторного запроса сервер передавал движку сигнал об отмене.

В ZIP входят движок и лицензия. Сервер и веб-интерфейс берутся из существующей установки.

## Как поставить рядом со сборкой 6

Из каталога установки DACAN скачайте архив и файл контрольных сумм в отдельную папку. После успешной проверки архив распакуется.

```sh
mkdir -p engine-sm75-20261119
(
  cd engine-sm75-20261119 &&
  base=https://github.com/tirex999/DACAN/releases/download/v0.1.42-sm75.20261119 &&
  curl -fL -O "$base/dacan-linux-x64-sm75.zip" &&
  curl -fL -O "$base/SHA256SUMS.txt" &&
  sha256sum -c SHA256SUMS.txt &&
  unzip dacan-linux-x64-sm75.zip
)
```

Скопируйте рабочий JSON модели в том же каталоге под именем `dacan-sm75.json`. В копии укажите в поле верхнего уровня `exe` абсолютный путь к `engine-sm75-20261119/dacan`. Пути к модели, токенизатору и библиотекам CUDA уже заданы в конфигурации. Чтобы запустить сборку на тех же картах, остановите текущий сервер и выполните команду из каталога DACAN в его окружении Python.

```sh
DACAN_SM75_NVFP4_PREFILL=1 python -m serve.server --engine dacan --config dacan-sm75.json --host 127.0.0.1 --port 8080
```

По умолчанию ускорение чтения промпта для SM75 выключено. Для возврата остановите этот экземпляр и запустите DACAN с исходным конфигом модели.
