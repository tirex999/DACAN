Пеликан на велосипеде: пятнадцать температур

Пеликан на велосипеде — SVG-картинка одним HTML-файлом. Модель Swift 1.5 Flash-Next (NVFP4 + Q8) на движке DACAN, две RTX 2080 Ti. Промт тот же, условия те же, меняется только температура: от 0.1 до 1.5 с шагом 0.1, по одному прогону на значение. Каждый файл можно открыть здесь же, скачать и посмотреть снимок.

Промт, дословно

Create svg image of a pelican riding a bicycle

Return a single complete HTML file with the SVG embedded inline and any CSS or JavaScript included in the same file. The HTML must open directly in a browser.

Что видно

Из 14 готовых прогонов три — работы уровня витрины по замыслу: 0.4 (пластина «Plate XIV» с телеметрией, ползунком и кнопками), 1.0 («Pelican Velo» с приборами каденса и уклона) и 1.4 («Field Plate» с пультом), причём у 1.4 сам рисунок с дефектом. Шесть — сцена с управлением (пауза, скорость, ночь), пять — простая сцена без управления. Богатые результаты выпадают на разных температурах, ровной зависимости от температуры нет, а на одной и той же температуре повторный прогон может дать совсем другой результат. Какая переменная решает исход — ищем, это следующий шаг. Прогон 1.5 ещё идёт, страница дополнится.
