DACAN build 6, Flash-Next NVFP4 + Q8. Два повторных прогона на рабочем Linux-стенде: четыре разных запроса одновременно, по 512 выходных токенов. Время включает приём промптов.

Как считали

Общая скорость = 2048 выходных токенов / время до завершения всех четырёх запросов. Получено 22,54 и 21,29 секунды. Это суммарная пропускная способность; скорость одного клиента указана отдельно.

Оборудование и профиль

2 × RTX 2080 Ti с 22 GiB на каждой, NVLink; 2 × Xeon 8358, 16 каналов DDR4-2666. Каждая карта связана со своей NUMA. Четыре слота, две группы, 64 CPU-потока без SMT. Контекст 1 048 576, KV int8, срок хранения разговорного кэша 120 минут.

Four-client throughput

Two repeated Linux runs produced 90.86 and 96.18 aggregate API tokens/s for four concurrent Russian requests, 512 output tokens each. Individual rates were approximately 23–25 tokens/s. Four concurrent English requests, 256 tokens each, reached 82.20 and 81.59 aggregate tokens/s. These short-prompt results include prompt admission and do not promise the same rate at all context lengths.

Hardware: two 22 GiB RTX 2080 Ti cards with NVLink, two Xeon 8358 CPUs and 16 DDR4-2666 channels. The separately named Linux reference archive contains the measured engine; the portable Linux and Windows builds passed loader/CLI checks. A new full-model GPU benchmark of each portable platform was not run.
